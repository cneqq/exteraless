# Личная ARM64 сборка

Actions → Personal release APK → Run workflow → main.
Используются Actions Secrets `API_ID` и `API_HASH`, а также постоянный ключ
подписи. Настройки старых запусков telegram_credentials/personal_signing удалены.

При запуске доступен выбор `optimization`:

- `quick` (по умолчанию) — быстрая сборка для проверки функций, без R8 и shrinkResources;
- `release` — полная оптимизация и уменьшение APK.

Оба режима используют release build type, один пакет и постоянную подпись, поэтому
обновляют друг друга поверх. Общий возрастающий versionCode сохраняется. Quick
может быть заметно больше и потреблять больше памяти/времени при первом запуске.
Ускорение не гарантируется до замера. Тестирование quick не заменяет проверку
оптимизированного release: R8 может менять поведение кода с reflection.
Для локальной быстрой сборки используется PERSONAL_FAST_BUILD=true.

Собирается release build type: debug-логирование future_auth_token по условию
BuildVars выключено. Обязательна постоянная личная подпись. Временная подпись
в workflow больше не используется. Сам вход и работа кошелька CI не проверяются.

Для установки нужен телефон Android 7+ с ARM64. Кошелёк GramWallet включён в исходниках;
нативный wallet engine входит в libtmessages.49.so. Проверка этого пути не является
аудитом ключей/seed phrase или гарантией работоспособности переводов.

## Начальные настройки

При отсутствии сохранённого выбора используется русский язык. Стандартные переводы
Telegram при необходимости загружаются штатным механизмом языковых пакетов; до
загрузки часть строк может отображаться на английском. Для установки без настроек
темы выбирается встроенная тёмная тема Night, автоматическое переключение выключено.
Сохранённые язык, тема и параметры автоночи не перезаписываются.
В дальнейшем их можно менять обычным способом в настройках.

В APK включены только английский и языки СНГ: en, ru, uk, be, kk, uz, ky, tg, tk,
hy, az, ro. Английские default resources остаются для отсутствующих переводов.
Список языков интерфейса в настройках ограничен тем же набором; уже активный другой
язык сохранён в списке. Полные переводы некоторых языков загружаются с Telegram:
наличие кода в фильтре не создаёт отсутствующий языковой пакет. Внешние языковые
ссылки и языки перевода сообщений этим не запрещены. Исходные переводы не удалены
из Git, чтобы облегчить слияние upstream; они исключаются из APK через localeFilters.
Это немного сокращает ресурсы, но не оптимизирует native/Java код.


## Telegram

Создать Actions Secrets `API_ID` и `API_HASH` в своём форке.
Workflow валидирует их до скачивания исходников и записывает как
TELEGRAM_APP_ID/TELEGRAM_APP_HASH в приватный local.properties.
Автоматической подстановки стандартных API вместо отсутствующих Secrets нет.
Не писать их в код, issues, поля запуска или сообщения CI. При компиляции эти
значения встраиваются в APK и доступны скачавшему его человеку. В публичном форке
Actions-артефакты могут скачать другие авторизованные пользователи GitHub.

## Постоянная подпись

Нужны ещё два Actions Secrets (в дополнение к API_ID/API_HASH):

- `RELEASE_KEYSTORE` — свой PKCS12/JKS-файл, закодированный в base64 одной строкой;
- `KEYSTORE_PASS` — пароль этого файла и ключа.

По умолчанию alias ключа — `personal`, пароль ключа совпадает с KEYSTORE_PASS.
Для существующего ключа с другими параметрами поддерживаются отдельные Secrets
`ALIAS_NAME` и `ALIAS_PASS`. Ключ и пароли сохранять резервной копией вне GitHub.
Не добавлять их в репозиторий, issues, логи, общедоступные артефакты или чат.
Workflow не генерирует новый ключ. При отсутствии Secrets он останавливается.
Gradle также запрещает временную подпись для PERSONAL_BUILD_ID=personal.
В готовом APK проверяется совпадение сертификата с настроенным хранилищем.
Публичный отпечаток сертификата записывается в build-info.json.

## Установка поверх предыдущей версии

Постоянный applicationId — `com.exteraless.app.personal`, название —
`Freezgram`. Java/JNI namespace остаётся org.telegram.messenger.
Версия из GitHub Actions получает versionCode = 1000000 + RUN_NUMBER * 1000 + ATTEMPT.
Следующий запуск и повторный запуск имеют больший versionCode. Не переименовывать
и не пересоздавать workflow без проверки счётчика: старая более высокая версия
не обновится на меньшую. Также не устанавливать результаты старых параллельных
сборок после более новых.

При неизменных пакете и ключе будущие APK обновляют эту личную установку,
сохраняя её приватные данные. Android всё равно может отклонить установку по
другим причинам (повреждение файла, нехватка места, ограничения устройства).

Переход с прежних копий b<RUN_ID>a<ATTEMPT> требует одной новой установки рядом.
У них другой пакет и временный ключ, удалённый после CI: обновить их поверх
новым ключом нельзя. Не удалять старую копию до переноса нужных данных и проверки
входа. Сессии, настройки и кошелёк автоматически между пакетами не переносятся.

Firebase-конфигурация upstream не подходит к произвольным новым пакетам. В таких
сборках не подключаются google-services/Crashlytics и не запрашивается FCM-токен;
пункт отправки crash reports скрыт. Вместо FCM по умолчанию используется существующее
постоянное соединение Telegram через keep-alive service. Проверьте получение
уведомлений после выключения экрана и настройте разрешения фоновой работы на своём
телефоне. Расход батареи может отличаться. Google Maps и другие сервисы с привязкой
ключей к пакету/подписи также требуют проверки; при необходимости используйте OSM.
Обычная локальная сборка без PERSONAL_BUILD_ID сохраняет прежний package и Firebase.

## Результат

После успешного запуска скачать ZIP из Artifacts: APK, SHA256SUMS.txt и build-info.json.
Артефакт хранится 3 дня. Workflow не публикует GitHub Releases и не пишет в Telegram.
Legacy workflows вынесены из .github/workflows и больше не запускаются автоматически.
Не включать их обратно с личными Secrets без проверки.

Обновлятор разработчика и установка APK из клиента удалены. Плагины и кошелёк
сохраняются: это не выполнение полного плана
безопасности из аудита. Плагины/developer/unsafe mode пока держать выключенными.
Для основного аккаунта и денег требуется дополнительная проверка.

## Ускорение

Собирается только arm64-v8a. Кэшируются downloaded Gradle dependencies, C++ ccache
до 2 GB и нативные результаты CMake/Chaquopy. Последние восстанавливаются только
при точном совпадении ключа исходников JNI, Chaquopy и файлов конфигурации сборки.
local.properties, signing files и Java/R8 outputs с API-реквизитами не кэшируются.
Объём heap Gradle выбирается по памяти runner (до 6 GiB), workers — до 4.
R8 включён только при optimization=release; quick пропускает этот этап. APK загружается без повторного сжатия.
Первый запуск заполняет новый кэш. Ускорение повторного запуска зависит от runner
и объёма изменений; точное время не гарантируется. Не используется SKIP — нативная
часть обязательна.

Инструменты: Java 21, Python 3.11, Gradle 9.7.1 с официальным wrapper checksum,
Android platform 37.0, Build Tools 36.0.0, NDK 27.2.12479018, CMake 3.31.6.
Actions закреплены SHA. Запуск только вручную, token contents:read, без posting/release.
