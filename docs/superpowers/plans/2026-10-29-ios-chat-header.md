> **For agentic workers:** Use superpowers:executing-plans to implement this plan in the current session.

**Goal:** Стеклянная iOS-шапка по согласованному скриншоту.
**Architecture:** Сохранить центрированный ChatAvatarContainer и действия. Для шапки выделить источник мягкого размытия и настроить существующие ActionBar/AGSL.
**Tech Stack:** Java, Android View/RenderNode/AGSL, pytest с Java harness.
**Spec:** ../specs/2026-10-29-ios-chat-header-design.md

## Global Constraints

Текущая no-plugins; без APK-сборки, установки, коммитов и push. Без новых зависимостей. Матовый вариант на неподдерживаемых конфигурациях.

## Review Focus

Приоритет iOS над Material; старый глобальный переключатель стекла; Android до 13 и энергосбережение; длинные имена; переходы поиска/выделения и специальные чаты.

Java harness: первоначально три проверки падают на отсутствующем отдельном выходе/политике и приоритете Material. После реализации проходят. Ревью обнаружило потерю нажатий на аватар при скрытом меню и влияние радиуса аватара на капсулу после поиска; оба замечания исправлены. Добавлена регрессия на реальный dispatchTouchEvent и область аватара.

Первый запуск pytest от корня зашёл в сторонние native-подмодули (включая WAMR malformed_test.py, конфликтующий с аргументами pytest). Набор проекта запускается через pytest tests. На Windows нужен Python -X utf8: иначе чтение существующих UTF-8 исходников тестами падает в cp1251. Эти сбои среды не требуют изменения исходников или существующих тестов.

Финальная проверка: python -X utf8 -m pytest tests -q --tb=short — 30 passed, 1 skipped (AAPT2), 2656 subtests passed. Целевые тесты iOS-шапки и навигации: 8 passed. Tree-sitter не нашёл ошибок синтаксиса Java, git diff --check прошёл. Результат полного набора включает параллельные изменения поля ввода из другой работы в общей папке; эти изменения сохранены. Android-компиляция, APK, установка и визуальные проверки на телефоне не выполнялись.
